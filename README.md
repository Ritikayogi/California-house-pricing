# California House Pricing 🔍🏡

This project focuses on predicting house prices in California using Machine Learning.  
It implements data preprocessing, feature engineering, model training, and prediction using a Linear Regression or Random Forest model.

---

## 📦 Software and Tools Required

Before running this project, make sure the following tools are installed on your system:

1. **[GitHub Account](https://github.com)**  
   To host and manage your project repository.

2. **[Heroku Account](https://heroku.com)**  
   For deployment (optional).

3. **[VS Code IDE](https://code.visualstudio.com)**  
   For editing and running your project files.

4. **[Git CLI](https://git-scm.com/book/en/v2/Getting-Started-The-Command-Line)**  
   To push/pull code using terminal commands.
